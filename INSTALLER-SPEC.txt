v3.10.27 installer design
- Primary project baseline: latest uploaded hsm-scheduler(8).zip, consolidated as v3.10.26.
- v3.10.27 consolidates the 16 Vercel API handlers behind one catch-all function while preserving public API paths.
- Handler source is moved outside the Vercel function discovery directory to server-api/.
- Existing files are permitted to change only when their SHA-256 matches the primary baseline manifest.
- Every changed file is backed up before replacement.
- New files are recorded for rollback.
- Native .NET Process execution is used for validation; no Start-Process, npx or cmd pipeline exit-code parsing.
- Tests run in controlled four-file Vitest batches.
- The release requires the staging branch and pushes only to origin staging.
- No Supabase migration is introduced by this phase.
