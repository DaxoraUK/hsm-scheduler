# Ground Control v3.10.5.4 — module roadmap baseline

This is a documentation-only release.

It establishes the first committed module roadmap under the one-module-at-a-time roadmap process:

- `docs/roadmaps/README.md`
- `docs/roadmaps/ANNUAL_PLANNER_SHARED_CALENDAR_COACH_REQUESTS_ROADMAP.md`

The roadmap records:

- the working baseline through v3.10.5.3;
- explicit Full Pitch and named-area hierarchy;
- operator approvals and alternatives;
- weather postponement, cancellation and rearrangement;
- separate winter sites with fixed seasonal slots;
- Manual, Assisted and Automatic Draft allocation;
- closure-impact handling and notifications;
- one shared analytics layer for Annual Planner Insights, main Analytics and grant evidence;
- permissions, RLS, audit, UX and acceptance standards;
- bolt-on packaging and commercial opportunities.

No React, Supabase schema, entitlement or runtime behaviour changes are included.
