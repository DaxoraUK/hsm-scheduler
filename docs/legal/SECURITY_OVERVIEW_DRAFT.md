# Daxora Ground Control Security Overview — Draft

**Status:** Customer-facing draft. Verify every claim against the deployed production environment before publication.

Potential verified controls to document include:

- Supabase authentication and signed user sessions.
- Club-scoped data ownership and forced Row Level Security.
- Role-based actions and trusted database audit events.
- Time-limited, owner-approved, read-only support access.
- Secrets held in server-side Edge Function configuration rather than browser code.
- Stripe-hosted checkout and customer billing portal.
- Backup, incident response, dependency management and deployment controls.

Do not claim certifications, penetration testing, encryption arrangements or recovery targets unless evidence exists.
