# Daxora Cookie and Storage Notice — Draft

**Status:** Draft for review.

Ground Control currently uses browser storage and authentication technologies needed to provide the signed-in workspace, preserve security state and remember user settings. The final notice should list each technology, provider, purpose and duration.

If analytics, advertising or other non-essential storage technologies are introduced, they must remain disabled until a compliant consent choice has been obtained. Strictly necessary storage should still be explained clearly.
