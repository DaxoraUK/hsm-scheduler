# Daxora Ground Control Subprocessor List — Draft

**Status:** Draft. Confirm contracts, processing locations and transfer safeguards before publication.

Likely service providers to assess include:

- Supabase — authentication, database, storage and Edge Functions.
- Stripe — subscription checkout, billing, invoices and payment administration.
- Hosting/deployment provider — web application delivery and logs.
- Weather and postcode providers — operational forecast and location resolution, where enabled.
- Email provider — transactional authentication, invitation and service messages, where configured.
- Error monitoring or analytics providers — only if later enabled with appropriate privacy controls.

For each provider, record the service, personal-data categories, processing location, contractual safeguard and change-notification process.
