# Draft intellectual-property asset schedule

**Working draft only. Review with an IP/M&A solicitor before use in a transaction.**

## Proposed included assets

### Software

- Daxora Ground Control application source code.
- Daxora League Manager source code.
- Coach Hub and Annual Planner source code.
- Shared user-interface components and design implementation.
- Scheduling, allocation, recommendation and operational engines.
- TeamFeePay acquisition-demo and partner-integration layer.
- Database migrations, functions and row-level security policies.
- Test suites, fixtures and release scripts.
- Deployment and environment templates excluding live secrets.

### Documentation and product knowledge

- Product audits and roadmaps.
- Module requirements and acceptance criteria.
- Release and rollout documentation.
- Product-decision records.
- Demonstration scripts and synthetic datasets.
- Integration specifications and API contract.
- Pilot and operational-learning materials permitted for disclosure.

### Brand and commercial assets, if specifically agreed

- Daxora and Ground Control names and logos.
- Relevant domains and social handles controlled by the founder.
- Website copy and sales collateral.
- Non-confidential prospect and pilot materials, subject to data protection and third-party rights.

### Transition knowledge

- Architecture walkthroughs.
- Domain-model workshops.
- Operational rules and edge-case explanation.
- Reasonable defect clarification and migration support for a defined period.

## Excluded unless separately agreed

- Founder personal hardware and accounts.
- Personal ChatGPT account and unrelated conversation history.
- Live HSM or other club personal data.
- Europa Components information, systems, data or intellectual property.
- Third-party open-source code beyond the rights already granted by its licence.
- Supplier accounts that cannot legally or practically be assigned.
- Personal email, financial, health or family records.
- Generic skills, experience and know-how that cannot be assigned.

## Required schedules before signing

- Repository and commit identifiers.
- Complete file manifest and cryptographic hash.
- Open-source dependency and licence inventory.
- Third-party service inventory.
- Domains and brand registrations.
- Contributor and contractor assignments, if any.
- AI-assisted-development provenance statement.
- Known defects and roadmap exclusions.
- Data and records excluded from delivery.
- Live credentials expressly excluded and rotated before handover.
